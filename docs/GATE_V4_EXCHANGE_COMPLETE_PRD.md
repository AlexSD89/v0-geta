> **核心定位**: Skills 的交易所、托管平台、对接枢纽
> **商业模式**: 动态定价 + 三种运营模式（即时/提案/竞赛）
> **技术连接**: MCP 协议对接 Claude/ChatGPT/Cursor/Coder等主流AI终端
> **日期**: 2026-02-01

## 一、核心定位：这是什么？

### 1.1 一句话定义

**Gate 是 AI Skills 的交易所（Exchange），提供托管、使用、对接和分销服务**

类比理解：
- **股票交易所**：买卖Skills，动态定价，打榜排名
- **Airbnb**：托管（我有房，Airbnb帮我管理）
- **App Store**：使用（我需要功能，直接下载）
- **Shopify**：开店（创作者独立站，展示价值数据）

### 1.2 不是什么？

❌ 不是简单的"技能商店"（只是买卖）
❌ 不是"工具集成平台"（只是连接）
❌ Gate 引擎不是主角（是平台内置调度工具）

### 1.3 核心价值主张

**对使用者**：一句话调度 1000+ Skills，在 Claude/ChatGPT/Cursor 中直接使用
**对创作者**：托管代码 → 开独立店 → 动态定价 → 赚取收益
**对平台**：连接 AI 终端（MCP 协议）+ 内容生态（Skills）+ 分销网络

## 二、技术连接层：对接主流 AI 平台

### 2.1 MCP 协议（Model Context Protocol）

**核心作用**：连接主流 AI 终端和 Gate Skills

```
Claude Desktop ──┐
ChatGPT         ├──► MCP 协议 ──► Gate Exchange ──► 1000+ Skills
Cursor          ├──►                                     │
Coder           ──┘                                      ▼
Windsurf                                            创作者托管的代码
```

**用户体验**：
1. 在 Claude 中输入："帮我深度调研 DeepSeek R1"
2. Claude 通过 MCP 协议调用 Gate 的 "DeepResearch" Skill
3. Skill 自动执行，返回结果给 Claude

## 三、商业模式：动态定价 + 三种运营模式

### 3.1 动态定价机制

**核心原则**：价格由市场决定，不是固定的

#### 定价因素

| 因素 | 影响 | 示例 |
|------|------|------|
| **使用量** | 用的人越多，价格可涨可跌 | 热门 Skill 涨价；推广期降价 |
| **声誉分** | 高分 Skill 可溢价 | 声誉 ≥ 80 分，溢价 +20% |
| **供需比** | 供不应求时涨价 | 只有 1 个 Skill，需求 100+ |
| **时间** | 峰谷定价 | 白天 +20%，夜间 -10% |
| **创作者定价权** | 创作者可自主调价 | 类似独立定价权 |

#### 定价示例

```
基础价格: ¥10/次
+ 声誉溢价 (+20%): ¥2
+ 峰时溢价 (+10%): ¥1
────────────────────
最终价格: ¥13/次
```

### 3.2 三种运营模式

#### 模式 1：即时模式（Immediate Mode）

**适用**：标准化、低门槛任务

| 特点 | 说明 |
|------|------|
| 定价 | 固定价格，按市场均价 |
| 分配 | 自动派单，算力最优 + SLA 最高 |
| 结算 | 完成即结算 |

**示例**：PDF 解析、数据清洗、文案生成

#### 模式 2：提案模式（Proposal Mode）

**适用**：复杂、非标任务，需要竞价

| 特点 | 说明 |
|------|------|
| 定价 | 创作者竞价报价 |
| 分配 | 客户选择最佳方案 |
| 结算 | 完成后评审付款 |

**示例**：深度投研报告、竞品架构分析、定制工作流

**流程**：
```
1. 客户发布需求："帮我分析竞品定价策略"
2. 多个创作者提交方案 + 报价
3. 客户选择方案A（¥500，3天交付）
4. 创作者完成，客户验收，平台结算
```

#### 模式 3：竞赛模式（Competition Mode）

**适用**：结果可衡量、需要SOTA效果，打榜机制

| 特点 | 说明 |
|------|------|
| 定价 | 悬赏金额，Winner Takes All 或 Top N 分成 |
| 分配 | 多方竞争，实时排行榜 |
| 结算 | 优胜者获得全部或大部分奖金 |

**示例**：Python 代码纠错挑战、视频生成大赛、最佳文案评选

**打榜机制**：
- **排行榜**：实时展示各个 Skill 的得分
- **悬赏池**：¥5000 悬赏，Top 1 拿 50%，Top 2-5 分 30%，参与奖 20%
- **评判标准**：准确率、速度、用户点赞数
