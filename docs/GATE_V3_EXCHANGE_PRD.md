# Gate Exchange v3.0 - 完整产品规划

> **核心定位转变**: Gate 是 Skills 的交易、托管和使用平台。Gate 引擎是平台内置工具。
> **关键术语**: Skills 是专属名词，保留英文，不翻译为"技能"
> **日期**: 2026-02-01
> **状态**: 规划中

---

## 一、批判性思维分析

### 1.1 当前问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 定位模糊 | Gate 既是产品又是平台 | 用户困惑：我来这里干什么？ |
| 命名混乱 | "运维大厅"、"工具集成"含义不清 | 导航点击率低 |
| 商业逻辑弱 | 没有明确的交易/收益展示 | 用户感受不到价值 |
| Gate 工具定位 | Gate 被当作主角宣传 | 应该是平台内置能力，不是主产品 |

### 1.2 核心洞察

**本质**：这是一个**双边交易所**

```
供给侧 (Creators)          交易所 (Gate Exchange)          需求侧 (Users)
  │                              │                              │
  │  上传技能/封装工作流  ──────►│◄────── 搜索/购买/使用技能    │
  │                              │                              │
  └──────── 获得收益 ◄───────────┴─────────── 支付费用 ─────────┘
```

**Gate 工具的角色**：交易所内置的"智能调度引擎"，帮助用户调度技能，而不是交易所本身。

## 二、产品架构重设计

### 2.1 一级导航（用户视角）

| 导航项 | 路由 | 核心功能 | 用户心智 |
|--------|------|----------|----------|
| **Skills 市场** | /market | 浏览、搜索、使用 Skills | "我来找 Skills" |
| **生态集成** | /ecosystem | MCP 协议 + 成熟 AI 工具 | "我看看能连什么" |
| **创作者中心** | /creators | 上传、管理、变现 | "我来赚钱" |
| **文档** | /docs | 接入指南、API、SDK | "我学习怎么用" |
| **关于 Gate** | /about | Gate 引擎介绍（原首页内容） | "了解 Gate 工具" |

### 2.2 二级页面规划

#### 2.2.1 技能市场 (/market)

**核心定位**：电商式技能货架

| 页面 | 路由 | 内容 |
|------|------|------|
| 市场首页 | /market | 搜索 + 分类 + 热门技能 + 推荐 |
| 分类浏览 | /market/category/[slug] | 按行业分类：法律/金融/营销/开发 |
| 技能详情 | /market/skill/[id] | 功能介绍 + 定价 + 评价 + API 文档 |
| 热门榜单 | /market/trending | 本周最热、收入最高、新上架 |

**关键交互**：
- 搜索框为核心（参考 Gemini 设计）
- 实时 Ticker 显示交易动态
- 按行业分类而非技术分类

#### 2.2.2 生态集成 (/ecosystem)

**核心定位**：展示 Gate 能连接的外部能力

| 页面 | 路由 | 内容 |
|------|------|------|
| 生态概览 | /ecosystem | 两大类：MCP 协议 + AI 应用 |
| MCP 集成 | /ecosystem/mcp | MCP 协议支持的工具列表 |
| AI 应用 | /ecosystem/apps | 成熟 AI 应用：Lovable、Cursor、Bolt 等 |
| Gate 引擎 | /ecosystem/gate | Gate 内置调度引擎介绍（原产品介绍） |

**关键点**：
- MCP 协议是连接外部工具的标准
- AI 应用是 Affiliate 合作（用户通过我们买，我们拿佣金）
- Gate 引擎是平台内置能力，不是独立产品

#### 2.2.3 创作者中心 (/creators)

**核心定位**：创作者的运营后台

| 页面 | 路由 | 内容 |
|------|------|------|
| 创作者首页 | /creators | 入门引导 + 收益概览 + 快速上传 |
| 我的店铺 | /creators/store | 管理我的技能、定价、数据 |
| 收益中心 | /creators/earnings | 收入统计、提现、交易历史 |
| 分销中心 | /creators/affiliate | 分销他人技能、佣金追踪 |
| 上传技能 | /creators/upload | 上传向导（信息→接口→定价→审核） |

**关键点**：
- Profile as Store：个人主页就是店铺
- 三阶段进化：托管 → 分销 → 共治

#### 2.2.4 文档 (/docs)

| 页面 | 路由 | 内容 |
|------|------|------|

## 三、命名规范

### 3.1 命名规范

**核心原则**：Skills 是专属名词，保留英文，不翻译

| 术语 | 使用方式 | 说明 |
|------|----------|------|
| **Skills** | 保留英文 | 专属名词，类似 App/iPhone |
| **Skills 市场** | 中英混搭 | 正确用法，Skills 是产品名 |
| **Skill** | 单数形式 | 单个技能单元 |
| **Gate** | 保留英文 | 平台名称 |
| **Gate 引擎** | 混搭 | 内置调度工具 |

### 3.2 页面命名

| 导航项 | 路由 | 说明 |
|--------|------|------|
| Skills 市场 | /market | 核心交易页面 |
| 生态集成 | /ecosystem | MCP + AI 应用 |
| 创作者中心 | /creators | 卖家后台 |
| 文档 | /docs | 接入指南 |
| 关于 Gate | /about | 平台介绍（原 Gate 产品内容） |

### 3.3 避免使用的命名

| 错误命名 | 问题 | 正确替代 |
|----------|------|----------|
| 技能市场 | 把 Skills 翻译了 | Skills 市场 |
| 运维大厅 | 含义不清 | 创作者中心 |
| 工具集成 | 太泛泛 | 生态集成 |
| AI 解决方案 | 和 Skills 重叠 | 删除 |
