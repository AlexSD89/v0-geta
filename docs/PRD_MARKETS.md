# Gate 双市场 PRD

## 1. 产品定位对比

### 1.1 AI 解决方案市场（原：AI 劳动力市场）

| 维度 | 说明 |
|------|------|
| **路由** | `/solutions-market` |
| **定位** | 封装好的 **知识+工作流** 方案，可一键 Fork/付费使用 |
| **类比** | Coze 模板商店、n8n 工作流模板、Zapier Templates |
| **核心价值** | 客户无需从零构建，直接复用行业最佳实践 |
| **内容** | 完整的业务场景方案（含知识库+工作流+外部工具配置） |
| **变现** | 方案使用付费、共创分佣 |

**用户故事**：
> "我是一个电商运营，我想让 AI 自动处理客服咨询，但我不知道怎么配置。
> 我在 AI 解决方案市场找到了'智能客服系统'方案，一键 Fork 后，
> 只需要绑定我的微信/淘宝账号，就能直接使用。"

---

### 1.2 集成工具库（原：AI 工具市场）

| 维度 | 说明 |
|------|------|
| **路由** | `/marketplace` |
| **定位** | Gate 能连接的 **外部工具/API** 列表 |
| **类比** | Zapier 集成目录、Make 连接器列表 |
| **核心价值** | 展示 Gate 的连接能力，建立用户信任 |
| **内容** | 外部工具列表（GitHub、Gmail、Slack、微信等） |
| **变现** | 不直接变现，是能力展示和信任建设 |

**用户故事**：
> "我想知道 Gate 能不能连接我公司用的 Salesforce 和钉钉。
> 我在集成工具库找到了这两个工具都是'可用'状态，
> 这让我相信 Gate 能满足我的需求。"

## 3. AI 解决方案市场 - 卡片设计优化

### 3.1 当前问题

1. **场景不够具体** - 用户看不出这个方案是否适合自己
2. **价值不够突出** - ROI/效率数据太小，不够抢眼
3. **行动不够明确** - "Fork"按钮含义模糊

### 3.2 卡片信息层级

\`\`\`
┌─────────────────────────────────────┐
│ [场景标签] 招聘 · 猎头 · B2B       │  ← 第一眼：场景匹配
├─────────────────────────────────────┤
│ LinkedIn 猎聘自动化                 │  ← 第二眼：方案名称
│                                     │
│ "让 AI 帮你找到最匹配的候选人，     │  ← 第三眼：核心价值（一句话）
│  从搜索到沟通全程自动化"            │
├─────────────────────────────────────┤
│ 🎯 效率提升 15x    💰 ROI 1200%     │  ← 第四眼：量化价值
├─────────────────────────────────────┤
│ [已连接] LinkedIn · Gmail · Slack   │  ← 第五眼：工具生态
├─────────────────────────────────────┤
│ [免费试用]           [立即部署 →]   │  ← 行动按钮
└─────────────────────────────────────┘
\`\`\`

### 3.3 核心优化点

| 优化项 | 原设计 | 新设计 |
|--------|--------|--------|
| 场景标签 | 单个类别 | 多个场景关键词（招聘、猎头、B2B） |
| 描述文案 | 功能描述 | 价值主张（"让 AI 帮你..."） |
| 数据展示 | 小字灰色 | 大字高亮，带图标 |
| 按钮文案 | "Fork" | "免费试用" / "立即部署" |
| 工具展示 | Badge 列表 | 带状态的工具图标 |

## 4. 集成工具库 - 内容优化

### 4.1 分类逻辑

\`\`\`
集成工具库
├── 生产力工具（Notion、Slack、Gmail）
├── 开发工具（GitHub、Jira、GitLab）
├── 社交媒体（微信、微博、LinkedIn）

### 4.2 状态设计

| 状态 | 颜色 | 含义 |
|------|------|------|
| 已连接 | 绿色 | 用户已授权连接 |
| 可用 | 蓝色 | 可立即连接使用 |
| 即将推出 | 灰色 | 正在开发中 |
