# Gate 平台完整架构

## 核心产品定位

### 1. Gate 平台（交易所）
- **定位**: Skills 的托管、交易、分享市场
- **颜色**: 蓝色系 (#0071e3)
- **功能**: 发现、Fork、收藏、购买 Skills

### 2. Gate AI（智能指挥官）
- **定位**: AI 能力编排系统，帮助用户使用 Skills
- **颜色**: 橙红色系 (#ff6b4a)
- **功能**: 智能路由、工作流编排、多 AI 协作

---

## 完整页面架构

### 一级页面（主导航）

1. **首页** `/`
   - Hero + 角色切换（使用者/开发者）
   - 平台对比（Gate 平台 vs Gate AI）
   - Skills 介绍
   - Skills 展示
   - 使用指南
   - 创作者 CTA
   - 合作伙伴

2. **Skills 市场** `/market`
   - 分类筛选
   - 搜索排序
   - 角色切换（使用者/开发者）
   - Skills 卡片网格
   - → 跳转到 Skill 详情页

3. **AI 工具市场** `/tools`
   - MCP 工具（免费托管）
   - SaaS 工具（如 Lawvable、Cursor）
   - API 服务
   - 托管申请 CTA

4. **Gate AI** `/gate-ai`
   - 智能编排介绍
   - 工作原理
   - 应用场景
   - 与平台的协同

5. **创作者中心** `/creators`
   - 上传 Skill
   - 管理 Skills
   - 收益分成说明
   - → 需要登录

6. **学习中心** `/about`
   - 什么是 Skill?
   - 快速开始 (`/docs/quickstart`)
   - Gate AI 介绍
   - AI 工具市场
   - 创建 Skill

---

### 二级页面

#### Skills 相关
- **Skill 详情** `/market/skill/[id]`
  - 完整描述
  - 安装方法
  - Fork/收藏/分享按钮
  - 代码示例
  - 评论区
  - **面包屑**: 首页 > Skills 市场 > Skill 名称

#### 文档相关
- **快速开始** `/docs/quickstart`
  - 安装 Claude Code
  - 连接 Gate 平台
  - 使用第一个 Skill
  - **面包屑**: 首页 > 学习中心 > 快速开始

#### 用户相关
- **个人中心** `/profile`
  - 用户信息
  - 角色切换（使用者/开发者）
  - 使用者模式: 我的 Forks、收藏、浏览历史
  - 开发者模式: 我的 Skills、收益数据、分析
  - **面包屑**: 首页 > 个人中心

- **仪表盘** `/dashboard`
  - 数据分析
  - Skills 管理
  - 收益报表

所有二级、三级页面都有面包屑，支持：
- 返回上一级
- 跳转到首页

- **未登录**:

  - 点击头像 → 个人中心

## 完整用户旅程

### 新用户（使用者）
1. 首页 → 了解平台 → 切换到"使用者"模式
2. 点击"浏览 Skills" → Skills 市场
3. 浏览/搜索 → Skill 详情页
4. 点击"Fork" → 提示登录
5. 登录/注册 → 个人中心
6. Fork 成功 → 安装到 Claude Code
7. 使用 Skill → 反馈/评分

### 创作者
1. 首页 → 切换到"开发者"模式
2. 点击"开始创作" → 创作者中心
3. 登录/注册 → 上传 Skill
4. 填写信息 → 发布
5. 个人中心（开发者模式） → 查看收益
6. 优化 Skill → 增加收入

### 学习路径
1. 首页 → "什么是 Skill?"
2. About 页面 → 侧边栏"快速开始"
3. 快速开始 → 安装教程
4. 侧边栏"Gate AI" → 了解智能编排
5. 侧边栏"AI 工具市场" → 发现更多工具
6. 底部 CTA → "探索 Skills 市场"
7. 闭环回到市场

## 关键交互

### Fork 功能
- 未登录: 弹出登录框
- 已登录: 
  - 复制到个人空间
  - 显示安装指南
  - 可编辑自己的 Fork

### 分享功能
- 生成分享链接
- 复制到剪贴板
- 分享到社交平台

### 收藏功能
- 红心动画
- 添加到收藏列表
- 个人中心查看

### 搜索功能
- 实时搜索
- 分类筛选
- 排序（热门、评分、最新）

## 技术实现

### 状态管理
- 用户登录状态（localStorage + Context）
- 角色切换（useState）
- 搜索/筛选（URL参数）

### 路由
- Next.js App Router
- 动态路由: `/market/skill/[id]`
- 查询参数: `/market?q=xxx&category=legal`

### 数据流
- 静态数据（演示阶段）
- 后续接入数据库（Supabase）
- API Routes 处理业务逻辑
